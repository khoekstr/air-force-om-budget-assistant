Privacy Policy

Last updated: October 1, 2026

What personal data is collected

The Air Force O&M Budget Assistant plugin itself does not independently collect, sell, or store personal data outside ChatGPT. It does not operate an external user-account system, payment system, or independent analytics system controlled by Kara Taylor.

If you voluntarily submit feedback through the project’s public GitHub Issues page, GitHub may associate the submission with your GitHub username and public profile, and the issue will contain whatever information you choose to submit. Please do not include classified, controlled, sensitive, proprietary, or personal information.

How personal data is used

The publisher does not use ChatGPT conversation data for advertising, profiling, sale, or unrelated purposes. Feedback submitted through GitHub Issues is used only to review the reported problem, improve the tool, or respond to the feedback.

Who receives personal data

ChatGPT conversations are handled by OpenAI under OpenAI’s applicable terms and privacy practices. The publisher does not independently receive or store those conversations outside ChatGPT.

Feedback submitted through GitHub Issues is provided to GitHub and is publicly visible to people who can view the repository. GitHub’s own terms and privacy practices apply to that content.

Retention

The plugin itself does not independently retain personal data outside ChatGPT. The publisher will remove feedback issue content from the active project repository within 12 months of submission when it is no longer needed for support or tool improvement. GitHub may retain copies or backups according to its own policies.

Your controls

You can edit content you submit through your GitHub account. To request earlier removal of feedback you submitted, open a GitHub issue titled “Privacy request” and identify the earlier issue by number. Do not include additional personal or sensitive information in the request.

Sale of personal information

Kara Taylor does not sell personal information collected through this plugin or support site.

Availability

The plugin is intended for public availability in the United States. This informational website may be accessible from other locations.

Changes

This policy may be updated as the tool evolves. The date at the top of this page will be updated when material changes are made.
