# Air Force O&M Budget Assistant

This repository hosts the interactive Air Force O&M Budget Dashboard and the public information, support, privacy, and terms pages for the Air Force O&M Budget Assistant ChatGPT plugin.

## Budget Dashboard

**[Open the Budget Dashboard](https://khoekstr.github.io/air-force-om-budget-assistant/dashboard/)**

The dashboard is published at `/dashboard/` within this repository's GitHub Pages website. The main website address opens the plugin information page.
